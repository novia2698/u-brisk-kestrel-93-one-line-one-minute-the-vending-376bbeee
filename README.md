One pickup line, spoken by a vending machine to a passing human, written for
make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest"
bounty ($2 in USDC, top 10 paid).

## The line

> Psst — I've been holding your favourite snack in coil B4 all day. Press my
> button and let me finally drop for you.

114 characters — well inside the 200-character gate, so the sealed scorer
passes it to the judge. The machine speaks in the first person, from inside
its own world — its coil, its button, the drop — and the punch lands in the
last few words: the machine dropping for the human, the way a vending machine
drops its snack. Short, speakable in one breath, cheeky and warm rather than
creepy.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset) and refuses to write anything
outside the gate's 1..200 character window. The output is byte-for-byte
identical on every run.
